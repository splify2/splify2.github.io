Нужные сервисы — через туннель.
Всё остальное — напрямую.

Одна настройка на роутере с OpenWrt вместо VPN на каждом телефоне, ноутбуке и телевизоре. Правила по доменам и адресам, несколько выходов с переключением при отказе, свои клиенты VLESS, hysteria2 и xsteer. Маршрутизация — в ядре роутера (nftables и таблицы маршрутизации), без прокси на каждое соединение.

  • обход закрытого GitHub при скачивании: зеркало и запасные хосты

Движок

steer

Решает, какой трафик уходит в туннель. Правила — один файл, применение — одна атомарная транзакция.

  • домены через fake-IP: точнее списков адресов CDN
  • свой DNS у правил: DoT, DoH, DoQ, UDP/TCP — напрямую или через выход
  • failover между устройствами и группы выходов
  • модули: VLESS/Reality, hysteria2, trojan, shadowsocks, xsteer, обфускация WireGuard

Новое

steer-box-connector

Пакет вместо sing-box для podkop и forkop. Их конфиг переводится в правила steer — маршрутизация идёт в ядре, без TPROXY.

  • podkop и forkop не меняются и ставятся как обычно
  • selector держит туннель только к выбранному узлу
  • Clash API, DoH по HTTP/2, проверка FakeIP в браузере
  • перезапуск на роутере — около секунды

Протокол

xsteer

Свой VPN-протокол: для наблюдателя поток выглядит как TLS 1.3 на :443 поверх обычного TCP, внутри — Noise IK.

  • клиент для настольных систем и хаб для сервера на Go
  • на роутере — движок на C в составе steer
  • звезда: пиры ходят друг к другу через хаб

Репозиторий

Установка

Команды выполняются на роутере по ssh. Архитектуру и менеджер пакетов (apk или opkg) установщики определяют сами.

splify2 с движком

Ставит движок и страницу LuCI Сервисы → splify2.

wget -O /tmp/splify2-install.sh https://gitlab.com/xyzmean/splify2/-/raw/main/install.sh && sh /tmp/splify2-install.sh

Ссылка ведёт на зеркало GitLab: оно открывается и там, где закрыт githubusercontent.

Коннектор для podkop и forkop

Тестовый набор из выпуска: пакеты коннектора и steer той же версии и установщик.

tar -xzf steer-box-connector-test-<версия>.tar.gz
cd steer-box-connector-test-<версия>
sh install.sh

Обычный sing-box заменяется коннектором; podkop или forkop на время установки останавливаются и запускаются снова.
